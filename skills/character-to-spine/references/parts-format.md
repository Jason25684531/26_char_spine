# parts.json 格式

寫在**圖片旁**：`<圖名>.parts.json`。工作目錄內的 `parts.json` 只是複本，改了會被覆寫。

只看這張圖本身判斷部件，不要參考其他角色的 `parts.json`。

## 結構

下面只示意結構，座標要依 `grid_overlay.png` 自己量，不要照抄任何數字。

```json
{
  "version": 1,
  "preset": "humanoid-chibi",
  "parts": [
    {"name": "hair_back", "polygon": [[x, y], "..."], "z": 0, "parent": "head", "role": "hair", "pivot": [x, y]},
    {"name": "body",      "polygon": [[x, y], "..."], "z": 3, "pivot": [x, y]},
    {"name": "head",      "polygon": [[x, y], "..."], "z": 5, "pivot": [x, y]},
    {"name": "arm_r",     "polygon": [[x, y], "..."], "z": 7, "pivot": [x, y], "attach": "book"},
    {"name": "book",      "polygon": [[x, y], "..."], "z": 6, "role": "prop", "pivot": [x, y]}
  ]
}
```

| 欄位 | 必填 | 說明 |
|---|---|---|
| `name` | 是 | 英數字與底線，不可重複，不可用 `root`、`hip` |
| `polygon` 或 `mask` | 二擇一 | 原圖像素座標（左上為原點）。`mask` 是與原圖同尺寸的灰階 PNG，白色為範圍，路徑相對於 parts.json |
| `z` | 是 | 前後順序，越大越前面，不可重複 |
| `pivot` | 否 | 關節位置 `[x, y]`：頭接脖子、手臂接肩膀、腿接髖部、頭髮根部、道具被握住的地方。省略時依部件類型估計 |
| `parent` | 否 | 跟著哪根骨頭動。必要部件由 preset 決定；其他部件預設 `body` |
| `role` | 否 | `head` `body` `arm` `leg` `hair` `skirt` `prop` `accessory` `ground`。必要部件由名稱推得；名稱為 `shadow` 時預設 `ground`；其他預設 `accessory` |
| `motion` | 否 | 動作幅度係數，預設 1.0，0 表示不動。只在確定某部件不該大動時才降低，品質檢查會自動處理會破圖的幅度 |
| `attach` | 否 | 必須保持接觸的部件名稱（或清單），見下方「手與道具」 |

**必要部件**（preset `humanoid-chibi`）：`head`、`body`、`arm_l`、`arm_r`、`leg_l`、`leg_r`。`_l`／`_r` 指**畫面**的左右，不是角色自己的左右。

**額外部件**：頭髮、裙擺、道具、配件、地面影子等會影響動畫的元素都拆出來，數量不限。`ground` 是地面影子：留在地上不跟著跳，不要給它 `parent`。影子的多邊形只圍住影子本身，**不要包到腳、鞋子或裙襬**；腿、裙子的多邊形要畫到最下緣，否則跳起時那些像素會留在地上。

## 使用者要求調整動作：motion_overrides

頂層選填欄位，使用者用自然語言要求調整動作時才寫：

```json
"motion_overrides": {"happy": {"energy": 1.3, "hair": 1.5}, "idle": {"energy": 0.8}}
```

- 鍵是動作名稱（`idle`、`happy`），值是倍率表。`energy` 乘在整段動作，`hair`、`skirt`、`accessory`、`arm`、`head`、`prop` 等 role 名稱只乘在該類部件。
- 倍率 0～2.5。「更活潑」約 1.3，「再多一點」約 1.5；「小一點」約 0.7。
- 加大動作也不會讓手離開抱著的道具（接觸約束優先）。加大後品質檢查若出現露出或穿插，照實回報，不要默默改回去。
- 沒寫 `pivot` 的頭髮、裙擺、飾品、道具，樞軸預設在它和父部件相接的地方。

## 手與道具

拿著或抱著東西的手，在手臂上寫 `"attach": "<道具名>"`，道具寫 `"role": "prop"`。骨架由**幾隻手 attach 同一個道具**決定：

- **一隻手拿著**（書、夾板、長杖、花束）：道具掛在手下，跟著手動。道具的 `pivot` 放在被握住的地方。
- **兩隻手抱著**（樂器、大箱子）：兩隻手都掛在道具下，道具擺動帶著手，手改用撥弦節奏。

初始姿勢中手與道具必須真的接觸（重疊或相距 3px 內），否則 rig 會要求修正。

## 寫多邊形的要點

- **範圍要包含被擋住的部分。** 手臂擋住身體時，身體的多邊形仍畫完整輪廓，被擋住的區域會自動補圖或列為修補任務。看得見的像素歸 z 最大的部件。
- **交界畫在真正的分界線上。** 頭與身體分在脖子，手臂分在肩膀，腿分在裙擺下緣或褲管。
- **相鄰部件互相重疊**幾個到十幾個像素（例如手臂蓋過肩膀），轉動時才不會透出細縫。
- **散落的特效**（花瓣、光點、金幣、背景光暈）不要包含在任何部件裡：系統會自動收進 `fx` 圖層（跟著角色跳、不轉動），不影響骨架位置。多邊形順手包到、但與角色不相連的特效也會自動移出部件。`fx` 是保留名稱。
- **邊緣不必畫到像素級**：多邊形外側貼著部件的髮絲、蕾絲、光暈會自動併入最近的部件；整塊漏畫的部位（尾巴、辮子）仍要自己畫，否則會被當成特效。
- **pivot 放在關節**，不要放在部件中央或外框角落。

## 超出範圍與看不到的部件

只支援有頭、身體、兩手、兩腳的角色（雙足的擬人動物也可以）。遇到下列情況，在頂層宣告，不要畫猜測的多邊形湊數：

- **必要部件完全看不到**（長裙蓋住雙腳、側身時遠側的手）：`"absent": ["leg_l", "leg_r"]`。該部件不建骨頭、不出動畫，報告列為可選擇補畫。`head`、`body` 不可列入。腳被長裙蓋住時，裙子用 `role: "skirt"`，`body` 的 pivot 放在腰。
- **對應不到這個骨架**（四足或無肢體的生物、多個角色、只有半身、坐姿或躺姿）：`"unsupported": "<原因>"`，`parts` 可以是空陣列。`c2s run` 會以結束碼 3 停止，把原因告訴使用者。
