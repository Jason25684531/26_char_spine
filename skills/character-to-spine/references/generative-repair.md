# 生成式補圖（Codex 內建 image_gen）

只在使用者明確同意（`c2s consent <圖片>`）之後使用。c2s 只收圖檔：對齊、只取被遮住的像素、原圖看得見的像素原樣保留、品質判定，全部由 `c2s prepare --generated` 完成。你不需要、也不應該自己處理圖片。

## 編輯目標

`output/<圖名>/gen_inputs/<部件>.png`：原圖，這個部件被其他部件遮住的區域塗成洋紅色（#FF00FF）。用 `view_image` 開啟後，以它為**編輯目標**呼叫 `image_gen`。不要用原圖、不要裁切。

## Prompt 範本

依部件填入兩處，其餘照抄：

```
編輯這張圖片：洋紅色（#FF00FF）的區域原本被{遮擋者，例如：吉他與手臂}擋住。
請把洋紅色區域補畫成{部件描述，例如：身體與紅色短袖上衣（胸前的彩色花朵裝飾、腰部），延續看得見的上衣}，
自然延續周圍看得見的形狀、材質與光影。
洋紅色以外的所有內容保持完全不變：構圖、畫布比例、角色位置與大小、姿勢、臉、服裝、顏色與 3D 材質，不要重新構圖或放大。
補畫的部分延續原角色的設計；肢體數量與關節位置正確。不要留下任何洋紅色，也不要畫出{遮擋者}。背景保持透明。
```

部件描述要寫看得見的特徵（顏色、花紋、材質），讓補畫接得上；遮擋者要明確寫出來，避免被重畫回去。

## 沒通過時怎麼改（同一部件最多 3 次）

| message 的原因 | 意思 | 下一次 prompt 只改這裡 |
|---|---|---|
| 可見區域對齊後誤差 | 生成圖把角色重畫或改了構圖 | 加強「洋紅色以外完全不變、不要重新構圖」 |
| 接縫色差 | 補上的部分和旁邊看得見的地方接不起來 | 部件描述補上接縫附近的顏色、花紋走向 |
| 沒有移除遮擋者 | 生成圖把吉他、花束畫回去了 | 加一句「這個區域裡不要出現{遮擋者}」 |
| 只有很少的生成內容 | 洋紅色區域被留空或仍是洋紅 | 強調「把洋紅色區域完整畫滿」 |
| 已經貼回原圖 | 你交了處理過的檔案 | 改交 image_gen 的原始輸出檔 |

第 3 次仍沒通過，該部件自動列為人工補畫。每次的融合結果都存在 `<圖名>.overrides/generated/<部件>_<n>_fused.png`，美術覺得可用時可以 `c2s prepare --replace <部件>=<該檔>` 匯入（狀態為人工確認，不是 AI 自動通過）。

## 誠實回報

- `ai_repaired` 只代表數值檢查通過。你在 `layers/<部件>.png` 看到殘留遮擋者（例如手心上的花瓣）、多出或少了肢體時，要寫進回報。
- 紀錄在 `<圖名>.overrides/provenance.json`：原圖、部件、prompt、工具、每次的量測值與判定、雲端處理許可。
